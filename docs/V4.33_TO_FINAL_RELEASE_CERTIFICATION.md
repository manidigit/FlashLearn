# FlashLearn — v4.33 → Final Release Certification

## Purpose

This document records the integrated specification boundary from v4.33 through the Final Release Certification while preserving the later v6.00 repository state. It is an additive certification record; it does not roll the repository back from v6.00.

## v4.33 — Localization / Accessibility Foundation

v4.33 remains the authoritative foundation document for the localization and accessibility architecture. Its original boundaries remain in force, including the distinction between localized resources and any remaining exhaustive hard-coded-string migration work.

## v4.34 — Education / Help

### Scope
Adds the Education / Help presentation layer without changing learning-state, review-history, difficulty, scheduling, or database behavior.

### Architecture
- Dedicated Help navigation destination.
- Settings provides the Help entry point.
- Help is presentation-only.
- Help does not write learning data.

### Invariants
- No Room schema change.
- No Learning State change.
- No Concept Difficulty change.
- No Review History change.
- No review scheduling change.

### Boundary
v4.34 does not by itself certify exhaustive migration of every legacy hard-coded string.

## v4.35 — TTS / Pronunciation

### Core Audio Contract
Every audio-quiz question is **Spanish**.

- **Word Recognition:** Spanish audio question → Spanish answer options.
- **Meaning Recognition:** Spanish audio question → Persian answer options.

The question language does not change with the answer-option language.

### Invariants
- TTS presentation does not change the correct-answer identity.
- Replay does not generate a different question.
- TTS does not mutate learning state, difficulty, review history, or scheduling.
- Device-specific Spanish voice availability remains an environment-dependent boundary.

## v4.36 — Full Integration Audit

Audits integration between localization, accessibility, Help, TTS, navigation, and the existing learning architecture.

### Integration Rules
- Presentation features remain separated from domain persistence.
- Settings → Help remains a presentation path.
- Locale changes do not rewrite stored learning content.
- TTS consumes the current quiz question as presentation input.
- Spanish remains the fixed audio-question language.

## v4.37 — Full Test & Stress Audit

Defines regression-sensitive verification around:
- Help navigation and return behavior.
- Quiz-language persistence.
- Spanish TTS semantics.
- Repeated TTS replay.
- Switching between Word Recognition and Meaning Recognition.
- Localization/settings isolation from learning records.

Source-level readiness must not be represented as an observed Android runtime result.

## v4.38 — GitHub CI Final

GitHub Actions is the authoritative repository build/test boundary.

A workflow file being present is not equivalent to a successful workflow execution. Actual CI PASS status must come from the corresponding GitHub Actions run.

## v4.39 — Release Candidate

The release-candidate contract freezes the architecture established by v4.33–v4.38 without changing learning-state semantics.

### Release Invariants
- Presentation settings do not mutate review history or scheduling.
- Localization does not rewrite stored learning content.
- Accessibility labels are not domain data.
- TTS remains Spanish for every audio question.
- Word Recognition remains Spanish → Spanish.
- Meaning Recognition remains Spanish → Persian.
