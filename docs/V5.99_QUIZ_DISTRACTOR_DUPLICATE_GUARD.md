# FlashLearn v5.99 — Quiz Distractor Rotation

## Reported defect
During one review session, subsequent quiz cards could reuse the same three wrong answers repeatedly.

## Implemented rule
- The review session keeps a set of distractor texts already used by earlier quiz cards.
- A new quiz question first filters those texts out.
- If at least three fresh valid distractors exist, the next card must use fresh distractors.
- If the vocabulary bank has fewer than three fresh valid distractors, the generator falls back to the complete valid pool rather than producing an invalid four-option question.
- The existing textual normalization, correct-answer uniqueness, canonical-key filtering, Vocabulary Difficulty pool rules, and Flashcard fallback remain in force.

## Quiz difficulty
EASY/MEDIUM/HARD now select deterministic rank bands from the same valid pool:
- EASY: three least-confusable candidates.
- MEDIUM: three middle-ranked candidates.
- HARD: three most-confusable candidates.

This keeps Quiz Difficulty separate from Vocabulary Difficulty and avoids a fixed-score MEDIUM rule that can select an unrelated distractor from a small pool.

## Verification
The regression suite includes a sequential-question test proving that, when enough candidates exist, the second question does not reuse the first question's three distractors.
