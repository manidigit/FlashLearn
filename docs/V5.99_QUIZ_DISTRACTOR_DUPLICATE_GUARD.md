# FlashLearn v5.99 — Quiz Distractor Semantic-Duplicate Guard

## Reported defect
A quiz could contain two wrong answers that were different strings but expressed the same alternative, for example:
- می‌توانی اسکایپ کنی؟
- امکان تماس با اسکایپ داری؟

The existing final validation only guaranteed that all four displayed strings were textually unique. That was insufficient because semantic/near-duplicate distractors can remain textually different.

## Implemented rule
After the EASY/MEDIUM/HARD ranking is produced, wrong answers are selected greedily with a pairwise near-duplicate guard:
- each new distractor must be below the configured pairwise lexical-similarity threshold against every already-selected distractor;
- if three mutually valid distractors cannot be selected, the existing FlashcardFallback path is used;
- the correct-answer uniqueness and canonical-key protections remain unchanged.

This is deterministic and local; no network or external AI service is introduced.

## Regression
QuizDifficultySelectionTest.distractorsCannotBeNearDuplicatePhrasingsOfTheSameAlternative reproduces the reported Skype collision and verifies that both near-duplicate alternatives cannot appear on one quiz card.
