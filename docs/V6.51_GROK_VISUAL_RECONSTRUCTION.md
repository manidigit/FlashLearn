# v6.51 — Grok Visual Reconstruction & Theme Contract

The supplied Grok screenshots are the visual source of truth for the Grok design language.

## Shared visual language
- Near-black/deep-navy background with warm gold accents.
- Thin gold borders and controlled elevation.
- Centered large screen titles with ornamental dividers.
- Dense dashboard composition and four-column statistics where space permits.
- Gold selected navigation pill.
- Compact grouped Review controls and gold selected states.
- Four statistic tiles and expanded vocabulary rows in Library.
- Dashboard cards, progress bars and chart containers in Progress.
- Grouped dark/gold sections in Settings.

## Theme ownership
FlashLearnThemeSpec -> ThemeDesign -> FlashLearnThemeTokens -> shared UI components -> screens.
Every visual parameter belongs to the active theme: palette, typography, density, spacing, corners, elevation, borders, dimensions, button/navigation style, stats/review/library layouts, review presentation/ornaments and semantic colors.

## Theme JSON v3
Custom theme JSON persists the complete ThemeDesign profile in a design object. Older JSON without design remains readable through the built-in profile fallback for the same theme id.
