# FlashLearn v5.98 — Quiz Generation Hardening

## Scope
This checkpoint hardens the Review → Quiz generation path around the two reported defects:
1. duplicate answer options can make a question ambiguous;
2. changing the quiz level can leave the wrong-answer set effectively unchanged.

## Implemented contract
- VocabularyDifficulty selects the documented candidate pool: same vocabulary difficulty first, then adjacent difficulty, then the whole eligible bank when necessary.
- QuizDifficulty is independent from vocabulary difficulty.
- EASY selects the least-confusable valid distractors.
- MEDIUM selects distractors closest to the middle of the confusability range.
- HARD selects the most-confusable valid distractors.
- Confusability is deterministic and local, using normalized lexical similarity plus category and entry-type compatibility. No network or external AI service is introduced.
- A distractor must belong to another active Concept and have both source/target language content.
- The correct target text and its canonical key cannot be reused as distractor content.
- The final option set must contain exactly four normalized-unique options and exactly one normalized occurrence of the correct answer.
- If three valid distractors cannot be produced, the question is rejected and the existing quiz fallback path is used; no duplicate option is manufactured to fill the slot.
- The quiz content bank is refreshed once at Review-session start so newly added or edited vocabulary is available without reloading the entire bank for every card.

## Regression coverage
QuizDifficultySelectionTest covers EASY / MEDIUM / HARD selection behavior, independence from Vocabulary Difficulty pool rules, and observable separation of difficulty bands when enough valid candidates exist.

QuizUseCasesTest continues to cover exactly four unique options, duplicate normalized text protection, missing source/target content fallback, inactive/same-concept exclusion, and candidate-pool ordering.
