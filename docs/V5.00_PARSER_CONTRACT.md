# FlashLearn v5.00 — Parser Contract Completion

## Scope
This milestone completes the parser-side metadata contract that was explicitly left pending in v4.95: Breakdown, Confidence, Relationship, Variant, and Import Log.

## Parser metadata
- `ParsedEntry.breakdown` preserves structured breakdown content.
- `ParsedEntry.relationships` preserves labeled relationships.
- `ParsedEntry.variants` preserves variants and derivative forms.
- `ParsedEntry.confidence` exposes deterministic parser confidence for entry creation/translation attachment.
- `ParseResult.importLog` records line number, original text, classified line type, and parser action.

## Compatibility
- Existing `parse(raw)` API remains unchanged and still returns `List<ParsedEntry>`.
- Existing notes and raw-line preservation remain intact.
- Exact duplicate merging now also merges structured metadata and keeps the highest confidence.
- No learning algorithm, review scheduling rule, or database schema was changed.

## Classification priority
Structured labels are classified before the generic note classifier, preventing `تجزیه:` / `breakdown:` lines from being downgraded to ordinary notes.

## Verification
Focused parser regression tests cover metadata extraction, confidence, deterministic import-log actions, existing duplicate behavior, orphan handling, and legacy parsing behavior. Full Android build/test remains the authoritative CI verification step.
