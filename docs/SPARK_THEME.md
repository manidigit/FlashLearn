# Spark Theme

FlashLearn's game-like learning theme.

- ID: `spark`
- Name: `جرقه`
- Primary: `#58CC02`
- Secondary: `#7C4DFF`
- Reward accent: `#FFB000`
- Filled semantic action icons
- Rounded, friendly cards and controls
- Light: `#F7F9F5`
- Dark: `#111713`

Spark is intentionally a distinct visual personality from Grok, Claud, and Modern Minimal.
