# v6.17 Stats/Review Adaptive UI Audit

## Root causes
- Quiz option controls used a fixed 72dp height while option text could wrap beyond that fixed height.
- Progress/Retention percentages occupied separate large vertical blocks, reducing compactness.
- Learning-stage bars used an artificial 0–100 normalization although the displayed values are counts.

## Implemented
- Quiz options retain a 72dp minimum and may grow with wrapped text; the label receives available horizontal width.
- Progress and Retention use compact title/value rows without changing calculated values.
- Learning-stage bars normalize against the largest actual stage count.
- No Review Engine, quiz generation/evaluation, scheduler, persistence, Room schema, or statistics calculation changed.

## Regression matrix
- RTL/LTR: global root direction preserved; no screen-local override.
- Light/Dark: existing MaterialTheme and theme tokens preserved.
- Long text/font scaling: fixed option height removed.
- Small screens: Review remains vertically scrollable.
- Accessibility/localization: no truncation or physical Left/Right workaround added.
