# FlashLearn v5.51 — Library / Add Word / Bulk Import Audit

## Scope
Audit of the v5.50 source baseline focused on Library search/filter behavior, Add Word persistence flow, Bulk Import parsing/result tracking, duplicate handling, parser metadata persistence, and release identity.

## Findings and fixes

### Library
- Fixed the Room `searchActive` query so the ViewModel's plain query text is bound as a true substring search.
- Spanish/Persian content and canonical keys now match anywhere in the text instead of requiring the caller to provide `%` wildcards.
- Existing active/favorite/category filtering behavior is retained.

### Add Word
- Existing save guard correctly requires non-blank source + target and blocks duplicate saves while persistence is in progress.
- Existing generation-safe category loading and protection against clearing newer user input during an in-flight save were retained.
- No learning, scheduling, or schema behavior was changed.

### Bulk Import
- Parser preview/result tracking from the existing contract is retained: READY, INCOMPLETE, IMPORTED, DUPLICATE, FAILED.
- Fixed atomicity: a parsed entry and its parser metadata are now persisted in one database transaction.
- A parser-metadata persistence failure can no longer leave a partially imported Concept/Content/Learning/Difficulty record.
- Batch duplicate tracking now records a pair only after a successful import. Failed items and items already present in the Library do not incorrectly make later identical entries look like same-batch duplicates.
- Existing canonical duplicate normalization remains based on the shared `computeCanonicalKey` contract.

### Release identity
- Advanced Android release identity from 5.50/50 to 5.51/51.
- Corrected the runtime preflight assertion to require versionName `5.51` and versionCode `51`.

## Invariants intentionally unchanged
- Learning Transition algorithm unchanged.
- Difficulty algorithm unchanged.
- Review scheduling/selection unchanged.
- Room schema remains version 5; no migration was introduced.

## Verification performed
- Source-tree static checks for the modified version gate, DAO search binding, atomic import path, and Bulk Import dependency wiring.
- New domain regression test added for parsed-entry + parser-metadata persistence.
- No nested ZIP was introduced into the release source tree.
- Full Android/GitHub Actions build execution remains the authoritative final compile/runtime verification step.
