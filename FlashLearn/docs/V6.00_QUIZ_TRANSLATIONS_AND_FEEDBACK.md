# v6.00 — Quiz Translation Display and Answer Feedback Timing

## Scope
This checkpoint addresses only the reported Quiz UX defects:
1. Quiz options previously exposed only the first target-language translation for a Concept.
2. After answer submission, the feedback state needed to remain visible long enough to distinguish correct and incorrect answers.
3. The Quiz should automatically advance after a fixed 3-second feedback interval without a manual continuation button.

## Implementation contract

### 1. Complete translation display
For every Concept used as a Quiz option:
- collect all non-blank target-language Content rows;
- order them by `translationIndex`, then Content UUID as a deterministic tie-breaker;
- remove normalized duplicate translation texts;
- display the complete translation group joined by ` / `.

The same rule is applied to the correct answer and distractors.

### 2. Option validity
The existing Quiz invariants remain unchanged:
- exactly four options when Quiz is generated;
- normalized option texts must be unique;
- the correct answer must occur exactly once;
- distractors must belong to different active Concepts;
- canonical-key duplicate protection remains active;
- if three valid distractors cannot be produced, the generator falls back to Flashcard.

### 3. Answer feedback
After a Quiz answer is successfully submitted:
- selected wrong option remains visible and is marked red;
- correct option remains visible and is marked green;
- feedback remains in the UI for 3,000 ms;
- the next Quiz card loads automatically;
- the previous manual `ادامه` action is not used.

The existing session-generation/session-id guards prevent a delayed coroutine from advancing a different or already-closed review session.

## Regression coverage
A domain regression test verifies that:
- the correct option contains all target translations;
- a distractor option also contains all target translations;
- individual first/second translations are not emitted as separate partial options.
